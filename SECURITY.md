# Security policy

## Supported versions

Fixes go into the latest release. Quarry is young (0.x), so upgrade to the newest version to get a
fix.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub:
[Report a vulnerability](https://github.com/quarry-luau/quarry/security/advisories/new).

Say what is affected and how to reproduce it. You will get an answer within a week, and a fix or a
plan once the report is confirmed. You will be credited in the advisory unless you ask not to be.
