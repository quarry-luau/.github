# Getting help

- **How do I...?** Start with the [README](https://github.com/quarry-luau/quarry#readme). Most of
  TanStack Query's [documentation](https://tanstack.com/query/latest/docs) applies too; the
  [differences](https://github.com/quarry-luau/quarry#differences-from-tanstack-query) are listed.
- **Something is wrong:** open an [issue](https://github.com/quarry-luau/quarry/issues/new/choose)
  with the smallest code that shows it.
