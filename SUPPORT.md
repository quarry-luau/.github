# Getting help

- **How do I...?** Start with the tool's README:
  [Quarry Query](https://github.com/quarry-luau/quarry-query#readme) (most of TanStack Query's
  [documentation](https://tanstack.com/query/latest/docs) applies too; the
  [differences](https://github.com/quarry-luau/quarry-query#differences-from-tanstack-query) are
  listed) or [quarry-tailwind](https://github.com/quarry-luau/quarry-tailwind#readme) (what
  compiles, and [where Roblox differs](https://github.com/quarry-luau/quarry-tailwind#where-roblox-differs)).
- **Something is wrong:** open an issue on the tool's repository,
  [quarry-query](https://github.com/quarry-luau/quarry-query/issues/new/choose) or
  [quarry-tailwind](https://github.com/quarry-luau/quarry-tailwind/issues/new/choose), with the
  smallest code that shows it.
